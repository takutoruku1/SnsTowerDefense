# SNS × タワーディフェンス

## 起動方法

ES Modules を使っているのでローカルサーバが必要です。

```bash
python3 -m http.server 8080
# → ブラウザで http://localhost:8080 を開く
```

または `npx serve` 等、任意の静的ファイルサーバで可。

## 現在の実装状況（MVP / Phase 2 完了）

| 項目         | 内容                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 技術         | HTML5 + Phaser 3 (CDN) / ES Modules                                  |
| 解像度       | 1280 × 720 (PC ブラウザ横長)                                         |
| フィールド   | 6 列 × 4 行のグリッド                                                |
| 主人公       | ピンク髪インフルエンサー（HP 段階で 3 種に差し替え）                 |
| 味方         | ざまぁwww (低コストアタッカー) ／ 擁護してる人えらい! (高 HP タンク) |
| 敵           | 荒らしマン (雑魚)   ／ 粘着アンチ (タンク)                           |
| 攻撃         | 味方は射程内の最近接敵に投稿を投擲 / 敵は接近で主人公に話しかけ攻撃   |
| 経済         | 初期 30、上限 100、毎秒 +1 自動回復                                   |
| WAVE         | 1 WAVE のみ（敵 9 体）                                               |
| 勝敗         | 全敵撃破 → WAVE CLEAR / 主人公 HP 0 → GAME OVER                      |

## 操作

1. 右パネルの味方カードをクリックして選択
2. 左フィールドのセルをクリックで配置（コスト消費）
3. 自動で味方が攻撃 → 敵を撃退

## アセットについて

実画像は `assets/` 配下に配置すると自動で読み込まれます。
不足分は Phaser のグラフィックスで自動的に仮スプライトが生成されます。
詳細は `assets/README.md` を参照。

## ディレクトリ構成

```
src/
├── main.js                 # Phaser 初期化
├── data/
│   ├── config.js           # 定数
│   ├── allies.js           # 味方データ
│   ├── enemies.js          # 敵データ
│   └── waves.js            # WAVE 定義
├── scenes/
│   ├── BootScene.js        # アセット読み込み / プレースホルダー生成
│   ├── GameScene.js        # メインゲームループ
│   └── UIScene.js          # UI（カード / HP / コスト）
└── entities/
    ├── Influencer.js       # 主人公
    ├── Ally.js             # 味方（タワー）
    └── Enemy.js            # 敵
```
