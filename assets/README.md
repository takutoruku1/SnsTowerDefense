# アセット配置ガイド

実画像を以下のパスに置くと、自動でプレースホルダーから差し替わります。
ファイルが無い場合は Phaser のグラフィックスで仮スプライトを生成します。

## 主人公（炎上系インフルエンサー）

**`influencer/happy.png` を 1 枚置くだけでOK。** 残りの2段階（stressed / broken）は
`BootScene.deriveInfluencerVariants` がランタイムにピクセル加工で自動生成します。

| HP 帯       | 状態     | 加工内容（自動）                                       |
| ----------- | -------- | ------------------------------------------------------ |
| 100%–66%    | 元気     | happy.png をそのまま使用                               |
| 66%–33%     | 焺り     | 30%脱彩 + 赤み + 汗マーク + 赤面斜線オーバーレイ       |
| 33%–0%      | ボロボロ | 強脱彩 + 暗化 + 青み + 涙 + ヒビ割れ + 暗幕            |

推奨サイズ: 縦長透過 PNG。背景透過必須（背景があると加工結果が汚くなる）。
モック準拠なら 220 × 320 px 〜 600 × 800 px くらいが扱いやすい。

> happy.png が無い場合は、Phaser のグラフィックスで 3 段階すべて図形プレースホルダーが
> 生成されるので、ゲームは即起動できます。
