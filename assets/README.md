# アセット配置ガイド

実画像を以下のパスに置くと、自動でプレースホルダーから差し替わります。
ファイルが無い場合は Phaser のグラフィックスで仮スプライトを生成します。

## 主人公（炎上系インフルエンサー）

HP 残量によって 3 段階で切り替わります。

| ファイル                          | HP 帯       | 状態         |
| --------------------------------- | ----------- | ------------ |
| `influencer/happy.png`            | 100%–66%    | 元気         |
| `influencer/stressed.png`         | 66%–33%     | 焺り         |
| `influencer/broken.png`           | 33%–0%      | ボロボロ     |

推奨サイズ: 220 × 320 px 前後、透過 PNG。

## 味方（投稿）

推奨サイズ: 128 × 128 px、正方形、透過 PNG。
