# デザインモック

ゲーム画面全体のデザインモックを HTML+SVG で再現したもの。
ピンク髪インフルエンサーを主人公にした「主人公差し替え版」。

## ファイル

- `design.html` — 単一ファイル。SVGで主人公を直接描画。

## 閲覧方法

```bash
# プロジェクトルートで
python3 -m http.server 8080
# → ブラウザで http://localhost:8080/mockup/design.html
```

または `design.html` をそのままブラウザで開いてもOK。

## 構成

- 左カラム: タイトル / 説明文 / **主人公（SVG）** / セリフ吹き出し / メンタルHPバー
- 中央カラム: 炎上エリアと SNSエリアの境界 / 敵×6（吹き出し付き） / 味方×3（射程円付き）/ 攻撃ライン / フィールド右端の主人公
- 右カラム: カテゴリタブ / 味方カード×6（ざまぁwww他）/ TL更新ボタン
- 下段: ゲームの流れ4ステップ + 勝利条件
- 最下段: 味方ステータス / コスト獲得 / 敵種類 / 特徴

## 用途

- 提供イメージとの方向性すり合わせ
- 実装時のレイアウト/配色の参照
- 関係者への共有用（スクショ撮ってSNSに貼るなど）
